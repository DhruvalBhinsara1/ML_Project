Methodology & System Architecture

About House Predictor

A predictive real estate analytics engine integrating statistical learning in R with low-latency API services in Flask. Designed to estimate housing market valuations, classify price tiers, and identify spatial-structural market clusters.

01 / Core Analytical Objectives

Residential real estate valuations exhibit non-linear behaviors governed by structural dimensions, layout densities, construction vintage, and spatial micro-markets. This platform models these factors through multi-paradigm statistical learning (continuous OLS estimation, recursive binary partitioning, bootstrap bagging, and standardized metric spaces) to produce reliable, explainable valuations.

02 / Statistical Models

OLS REGRESSION

Ordinary Least Squares

Continuous price valuation modeling carpet area, BHK layout, property vintage, and target-encoded city price indexes.

DECISION TREE

Decision Tree (CART)

Hierarchical decision rules partitioning data based on Gini impurity to classify units into Budget, Mid-Range, and Premium brackets.

RANDOM FOREST

Random Forest Ensemble

100 decorrelated decision trees using bootstrap aggregating (bagging) to minimize variance and stabilize classification boundaries.

NEAREST NEIGHBORS

K-Nearest Neighbors (KNN)

Metric-space classifier computing normalized Euclidean distances across candidate feature vectors (calibrated $K=11$ at $88.68\%$ accuracy).

HIERARCHICAL CLUSTERING

Agglomerative Clustering

Bottom-up grouping utilizing Ward's minimum variance criteria to generate high-resolution submarket dendrograms.

03 / Computational Pipeline & Tech Stack

R-Lang 4.4.2 Python 3.11 Flask WSGI rpart • randomForest • caret Target-Mean Encoding Binary RDS Catalog (3.7 MB) Vanilla JS ES6
High-Cardinality Dimensionality Reduction: All 42 municipal territorial factors are smoothed via target-mean encoding to prevent combinatorial tree-branching bottlenecks, enabling sub-second inference across all models.

04 / Research Provenance

Architected as a unified machine learning research and appraisal system. Employs a strict decoupling between data pre-processing, statistical computation in R, and human-centric presentation in Flask.

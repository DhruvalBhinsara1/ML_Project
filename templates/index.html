About House Predictor

House Predictor is a machine learning-based real estate analytics system designed to analyze housing information, predict property prices, classify property segments, and group similar properties.

Project Objective

The project demonstrates how machine learning can be applied to housing data to support property price prediction, property classification, and exploratory analysis of similarities between properties.

Machine Learning Models

Linear Regression

Predicts the continuous estimated price of a property from selected property characteristics.

Decision Tree

Uses decision rules based on property characteristics to classify properties into different segments.

Random Forest

Combines multiple decision trees to provide an ensemble-based classification approach.

Hierarchical Clustering

Groups similar properties using hierarchical clustering and visualizes the relationships through a dendrogram.

How the System Works

Users enter property information or select clustering parameters through the web interface. The backend processes the inputs and connects them with the corresponding machine learning workflow. The system then returns a prediction, classification result, or clustering visualization.

Analysis: The system uses housing attributes such as property size, BHK, property age, city, and other available characteristics depending on the selected model.

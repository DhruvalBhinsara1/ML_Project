About House Predictor

An end-to-end real estate predictive analytics platform integrating multiple statistical and machine learning methodologies to forecast housing valuations, categorize market tiers, and uncover spatial-structural clusters.

Core Objectives

Modern housing markets present significant non-linear relationships between physical dimensions, geography, and valuations. This system serves to demonstrate how robust multi-paradigm machine learning (regression, classification, clustering) can provide clear transparency and actionable real-estate insights.

Machine Learning Architectures

Linear Regression

Estimates continuous property pricing using multi-variable Ordinary Least Squares with calibrated target-encoded geographic indices.

Decision Tree (CART)

Constructs explainable hierarchical decision rules based on information gain and Gini impurity to segment properties into distinct price brackets.

Random Forest

Ensemble of 100 decorrelated decision trees using bootstrap aggregating (bagging) to minimize variance and enhance classification stability.

Hierarchical Clustering

Agglomerative clustering utilizing Ward's minimum variance criteria to construct high-resolution taxonomic dendrograms.

Engineering Stack

Python 3.11 Flask Web Framework R Statistical Language rpart & randomForest Semantic HTML5 Modern Responsive CSS Vanilla JavaScript
Production Optimization: All 42 high-cardinality municipal factors are smoothed via target-mean encoding to eliminate exponential factor-split bottlenecks, allowing sub-second inference across all models.

Project Collaboration

Developed as a collaborative machine learning research project. Designed with modular architecture separating data pre-processing, statistical modeling in R, and web API presentation in Flask.
